## Key Learning

1. Large Language Models (LLMs)
A. Deep learning models trained on vast amounts of text data to understand, generate, and process human language. They work by predicting the most statistically likely next word (or token) based on patterns learned during training.

2. What Prompts Are
A. Inputs—text, code, or instructions—given to an LLM to guide its output. A prompt sets the context, task, and constraints for the model's response.

3. How Prompts Influence Responses
A. Prompts act as dynamic boundaries. Specific phrasing, persona assignments, clear formatting instructions, and contextual details directly steer the model's tone, accuracy, length, and depth.

4. Randomness in LLM Outputs
A. LLMs do not produce identical outputs every time because they select words based on probability distributions rather than hardcoded rules. Randomness is controlled by parameters like:
•	Temperature: Lower values (0.0 to 0.3) make outputs deterministic and focused; higher values (0.7 to 1.0+) increase randomness and creativity.
•	Top-P (Nucleus Sampling): Limits selection to a percentage pool of the most probable next words.

5. Basic Prompting Concepts
•	Zero-Shot Prompting: Asking the model to perform a task directly without providing examples.
•	Few-Shot Prompting: Providing a few input-output examples inside the prompt to demonstrate the desired pattern.
•	Chain-of-Thought: Instructing the model to solve complex tasks step-by-step to improve reasoning accuracy.
•	Role/Persona Prompting: Telling the model to act as a specific entity (e.g., "Act as a senior software developer").
